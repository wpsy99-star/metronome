# Measure · 악보 연습실

로그인 없이 스캔 악보를 가져와 ABC 코드를 편집하고, 음표를 클릭한 위치부터 연습하는 앱입니다.

## 설치·실행

현재 클라우드 환경에는 의존성과 Audiveris가 설치되어 있습니다.

```sh
cd /workspace/metronome
npm start
```

기본 포트는 3000입니다. 다른 포트가 필요하면 `PORT=3001 npm start`로 실행합니다. 기본 바인딩은 로컬이며, 외부 개발 서버 연결에는 `HOST=0.0.0.0 npm start`를 사용합니다.

새 Linux x86_64 환경에서는 Node.js 22.13 이상, Python 3, curl, dpkg-deb가 필요합니다.

```sh
bash scripts/setup.sh
npm start
```

설치 스크립트는 고정 버전 Audiveris 5.11.0과 영어 OCR 데이터를 다운로드하고 SHA-256을 검증합니다. Java 런타임은 Audiveris 배포본에 포함됩니다. Ubuntu 22.04용 배포본을 사용하므로 다른 운영체제에서는 별도 Audiveris 설치 후 `AUDIVERIS_BIN`에 실행 파일 경로를 지정하세요.

## 사용 방법

1. **스캔 악보 가져오기**에서 PNG/JPG/PDF(최대 20MB)를 선택하고 변환합니다. 인식 결과와 원본이 저장됩니다.
2. **ABC 코드** 탭에서 인식 결과를 수정합니다. 악보가 자동으로 다시 그려지며, **변경사항 저장**으로 DB에 보관합니다.
3. 악보의 음표를 클릭하면 그 음부터 피아노 소리로 재생됩니다. 재생 중인 음표는 주황색으로 표시됩니다. 재생 버튼은 일시정지·다시 재생, ↺는 처음으로 이동합니다.
4. BPM은 30–240 범위의 **4분음표 기준**입니다. 템포 변경 시 재생은 멈추고 처음으로 이동합니다. 메트로놈 소리를 켤 수 있습니다.
5. 왼쪽에는 **최근 등록 5개**가 보입니다. **내 악보**는 전체 목록과 제목 검색을 엽니다. 삭제 전에 확인합니다.
6. **ABC 직접 입력**으로 스캔 없이도 새 악보를 만듭니다. 저장하지 않고 이동할 때는 확인합니다.

로그인과 사용자 구분이 없으므로 한 서버의 악보 목록을 공유합니다. 기본 데이터 위치는 `data/measure.sqlite`, 원본은 `data/uploads/`입니다. 백업 시 두 항목을 함께 보관하세요. `MEASURE_DATA_DIR`로 데이터 위치를 바꿀 수 있습니다.

## 구현

- Express + Node 내장 SQLite: 악보 저장·수정·삭제, 파일 업로드와 원본 조회
- abcjs: ABC 악보 렌더링 및 오디오 생성. 클릭한 음의 ABC 위치를 재생 이벤트에 연결
- Web Audio 시계를 기준으로 재생과 음표 색상 동기화. 피아노 음원은 서버에 포함되어 외부 음원 서버 요청 없이 재생
- Audiveris OMR → MusicXML → Python 변환기 → ABC. 외부 AI API 호출, 비용, API 키는 필요하지 않음

OpenAI 이미지 모델의 추가 검수 기능은 연결하지 않았습니다. 현재 악보 인식 엔진은 Audiveris입니다.

## 인식 범위와 제한

선명한 인쇄 악보를 권장합니다. 너무 작은 이미지·손글씨·복잡한 악보는 오인식할 수 있으므로 원본과 결과를 비교하세요. 스캔 한 건을 순차 처리하며 최대 4분 후 중단합니다. 지원하지 않는 파일은 거부합니다.

MusicXML 변환기는 일반 음표, 쉼표, 화음, 여러 성부, 음가, 붙임줄, 기본 반복 기호를 처리합니다. 조성은 C로 표시하고 음높이는 명시적인 임시표로 유지합니다. 장식음은 자동 변환을 거부합니다. 박자 변경, 이조 악기, 반복 엔딩, 부분 붙임줄은 자동 변환을 거부합니다. 표현 기호의 충실한 변환은 추가 작업이 필요합니다. 생성 ABC를 직접 수정할 수 있습니다. 재생 음색은 피아노이며 음원 범위는 A0–C8입니다.

## 검증

```sh
npm test
```

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용합니다. `CHROMIUM_PATH`로 변경할 수 있습니다. DB API 검증, 실제 브라우저 편집·저장·새로고침 복원·목록·삭제·BPM·음표 클릭 재생·오디오 시간과 색상 일치, 42음 스캔의 실제 Audiveris 인식·ABC 저장·재생을 확인합니다. 테스트 데이터는 임시 디렉터리에 격리합니다.

`ui/`는 과거 승인용 시안입니다. 실제 앱은 `public/`와 `server.js`이며, HTML을 다운로드해 여는 방식으로는 서버 기능이 작동하지 않습니다.
